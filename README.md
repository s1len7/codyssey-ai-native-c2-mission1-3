# codyssey-ai-native-c2-mission1-3

민수 님이 만든 영화 티어리스트를 직접 써 보고, 민수 님이 받은 AI 검토와 동료 피드백을 확인한 뒤 민수 님께 도움이 되는 피드백 하나로 다시 쓴 미션 1-3 결과물입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `backup/` | 미션 안내 문서와 샘플 (`[미션3]샘플과 코랩세션질문지`) |
| `민수_영화티어리스트.html` | 검토 대상 영화 티어리스트 (있다면) |
| `민수_기획서.md` | 검토 기준이 되는 기획서 (있다면) |
| `받은_피드백.md` | 민수 님이 받은 AI 검토와 동료 피드백 (있다면) |
| `미션3_기록.md` | 확인 결과와 판단 기록 (있다면) |
| `피드백.md` | 민수 님께 보낼 피드백 (있다면) |

## 샘플 실행

`backup/[미션3]샘플과 코랩세션질문지/샘플/민수_영화티어리스트.html`을 더블클릭하면 브라우저에서 열립니다. 외부 파일, 로그인, 서버 실행 없이 HTML 한 장으로 동작합니다.

## 기획서 요약 (샘플)

- **누가 쓰나**: 민수와 영화를 좋아하는 친구들
- **무엇을 하려고**: 본 영화를 S/A/B/C 등급으로 나누어 내 취향을 정리
- **화면과 동작**: 위에 S/A/B/C 칸, 아래에 아직 안 정한 영화 카드. 카드를 누르고 등급 글자를 누르거나 끌어 놓으면 해당 칸으로 이동. 제목 입력 후 '추가'로 새 카드 생성. '처음으로'로 초기 목록 복원
- **필요한 자료**: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리 (총 8편)
- **완성 기준**: 영화가 한 칸에만 있고 옮긴 칸에 남음. 제목을 입력하면 새 영화 카드가 생김. 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남음. 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있음. '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 복원. 외부 파일이나 로그인 없이 HTML 한 장으로 열림

## 미션 1-3 기록

`민수_영화티어리스트.html`을 덮어쓰지 않고 보관한 뒤, 완성 기준과 받은 피드백을 하나씩 시험해 확인했습니다. 확인 결과와 민수 님께 보낼 피드백은 `미션3_기록.md`, `피드백.md`를 참고하세요.

## 메모

- AI 검토: 저장 기능 없음, '처음으로'가 직접 추가한 영화를 지우지 않는다는 지적은 실제와 다름, 빈 제목을 막지 않음
- 동료 피드백: 휴대폰에서 불편, 카드 이동 동선, 칙칙한 카드 색, 포스터 사진, C칸 필요성 등
